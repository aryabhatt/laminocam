# Contact

For questions, issues, or feedback regarding Tomocam, please reach out through one of the following channels:

## Innovation & Partnerships Office

**Berkeley Lab Innovation & Partnerships Office (IPO)**
- Email: IPO@lbl.gov
- Handles licensing, intellectual property, and rights to use/distribute the software

## Project Information

Tomocam is developed at Lawrence Berkeley National Laboratory as part of the Advanced Light Source (ALS) program.

## Reporting Bugs

If you encounter bugs or issues:

1. Check the [Configuration Reference](configuration.md) for parameter guidance
2. Try the memory estimation scripts to rule out memory issues
3. Consult the [Theory & Algorithms](theory.md) section for convergence tips
4. Contact IPO@lbl.gov with details about your issue, including:
   - Configuration file (with paths removed if sensitive)
   - Error message or unexpected output
   - System information (OS, hardware, compiler version)
